À propos du projet

Projet de programmation Web TI504N - EFREI Paris - 2026/2027

Le projet

La Coupe du Monde des Saveurs est un site réalisé dans le cadre du cours de programmation Web. L'idée était de mélanger deux choses que tout le monde aime : le football et la cuisine. Le site est fait uniquement en HTML5, CSS3 et JavaScript, sans framework ni bibliothèque. Toutes les images (drapeaux, plats, logo) sont des fichiers SVG que nous avons faits nous-mêmes.

À savoir

  • La compétition et les résultats sont fictifs, ils ont été inventés pour le projet.
  • Les votes sont enregistrés dans le navigateur (localStorage), ils ne sont pas envoyés sur un serveur.
  • Le projet a été géré avec Git et GitHub, et organisé avec un tableau Trello.
